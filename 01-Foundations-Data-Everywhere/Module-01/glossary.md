Este documento consolida a terminologia técnica primária introduzida no Módulo 1, com o objetivo de padronizar a linguagem arquitetônica e analítica durante o aprendizado.

| Termo Analítico | Definição Técnica |
| :--- | :--- |
| **Habilidades Analíticas** | Qualidades e características associadas ao uso empírico de fatos para a resolução de problemas corporativos. |
| **Pensamento Analítico** | Processamento metodológico que envolve a identificação, definição e solução de um problema através do uso organizado de dados. |
| **Contexto** | A condição, ambiente ou premissa de negócios em que um evento, dado ou anomalia existe ou ocorre. |
| **Dados (*Data*)** | Uma coleção bruta de fatos informacionais, quantitativos ou qualitativos. |
| **Análise de Dados (*Data Analysis*)** | A coleta, transformação e organização de dados para extrair conclusões, formular predições e direcionar decisões. |
| **Analista de Dados** | Profissional técnico que gerencia, transforma e modela dados operacionais para inferir conclusões de negócios. |
| **Análise Avançada (*Analytics*)** | A exploração científica de dados ("A ciência dos dados aplicada"). |
| **Design de Dados** | A arquitetura lógica e estrutural de como as informações são guardadas e acessadas num sistema. |
| **Decisão Orientada a Dados (*Data-Driven*)** | A prática de substituir instinto corporativo por fatos concretos na formulação da estratégia de negócios. |
| **Ecossistema de Dados** | Estrutura unificada e interconectada de elementos de *hardware*, software, pessoas e processos para capturar e analisar dados. |
| **Ciência de Dados (*Data Science*)** | Campo multidisciplinar avançado focado na criação de novos modelos algorítmicos para entender padrões ocultos. |
| **Estratégia de Dados** | A arquitetura de governança sobre como pessoas, procedimentos e ferramentas lidam com dados em grande escala. |
| **Visualização de Dados** | A tradução matemática de bancos de dados para representações gráficas facilmente compreensíveis. |
| **Conjunto de Dados (*Dataset*)** | Matriz consolidada de registros e atributos que operam e podem ser manipulados como uma única unidade lógica. |
| **Análise de Lacunas (*Gap Analysis*)** | Metodologia técnica para investigar o hiato entre o estado atual da operação e o objetivo futuro projetado. |
| **Causa Raiz** | A falha sistêmica basal ou o motivo primário deflagrador de um problema processual em cadeia. |
| **Mentalidade Técnica** | Habilidade cognitiva de fragmentar problemas macro em estruturas menores, abordando-as de forma lógica e sequencial. |
